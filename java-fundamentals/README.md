# Java Fundamentals

Área dedicada ao registro dos meus estudos sobre os fundamentos da linguagem Java.

Este diretório não representa um projeto ou uma aplicação completa. Seu objetivo é reunir exercícios, anotações e exemplos desenvolvidos durante minha preparação técnica, permitindo acompanhar a evolução do meu aprendizado.

![Banner Java Fundamentals](./assets/banner-readme.png)

## Objetivo

Fortalecer minha base em Java por meio da prática de lógica de programação, resolução de problemas e compreensão dos principais recursos da linguagem.

Os códigos deste diretório funcionam como registros do processo de aprendizagem. Cada exercício representa um conceito estudado ou uma habilidade praticada.

Cada exercício possui seu próprio diretório e um arquivo `Main.java`.

## Referências dos exercícios

Parte dos exercícios foi baseada em problemas introdutórios da plataforma [Beecrowd](https://www.beecrowd.com.br/).

Os enunciados e links para os problemas originais estão registrados nos arquivos correspondentes.

Os códigos são mantidos como registros de estudo e podem conter mensagens interativas ou adaptações didáticas diferentes do formato de saída exigido por juízes online.

## Próximos conteúdos

Conforme os estudos avançarem, este diretório poderá receber conteúdos sobre:

- estruturas de repetição;
- arrays e matrizes;
- strings;
- métodos;
- classes e objetos;
- encapsulamento;
- herança;
- polimorfismo;
- interfaces;
- coleções;
- tratamento de exceções;
- leitura e escrita de arquivos;
- testes automatizados.

## Contexto

Este diretório integra o repositório [Android Embedded Systems Lab](../README.md) e reúne exercícios utilizados para fortalecer fundamentos relevantes ao desenvolvimento Android com Kotlin.

O estudo de Java contribui para reforçar conceitos de lógica, orientação a objetos e organização de código que também são importantes no desenvolvimento Android com Kotlin.
